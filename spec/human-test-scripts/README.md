# Human test scripts

These scripts are manual QA checklists for core user journeys in the Flutter app.

## How to use

- Run the app (dev flavour is fine).
- Start each script with a **fresh local profile** unless the script says otherwise.
- Record deviations as notes: device + OS, build/flavour, and the exact screen/label that differed.
