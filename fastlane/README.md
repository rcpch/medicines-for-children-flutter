Fastlane lanes require environment variables to be set by CI.

Required for iOS TestFlight:
- ASC_KEY_ID
- ASC_ISSUER_ID
- ASC_KEY_P8
- IOS_BUNDLE_ID
- APPLE_ID

Required for Android Internal App Sharing:
- ANDROID_PACKAGE_NAME
- PLAY_SERVICE_ACCOUNT_JSON
- ANDROID_KEYSTORE_PATH
- ANDROID_KEYSTORE_PASSWORD
- ANDROID_KEY_ALIAS
- ANDROID_KEY_PASSWORD
