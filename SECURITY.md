# Security Policy

## Reporting A Vulnerability

Do not report security vulnerabilities through public GitHub issues.

Report them privately using GitHub's private vulnerability reporting from the repository's **Security** tab, or email <security@bawmedical.co.uk>. Do not include real child, carer, medicine, administration, credential, passphrase, token, or backup data in a report or proof of concept.

Please include a description of the issue and impact, safe reproduction steps, affected versions or commit, and any suggested mitigation. Expect an initial acknowledgement within three working days and a substantive response within ten working days.

## Scope

This policy covers the code and release artefacts in this repository. Upstream vulnerabilities should also be reported to the relevant maintainer, but report them here privately when they affect this application.

## Clinical Safety

Flag any issue that could show the wrong child or medicine, alter or omit a schedule or administration, expose health data, misidentify a scanned medicine, or prevent access to an accurate schedule. Security issues with potential care impact are also clinical safety issues and will be prioritised.

## Disclosure

We use coordinated disclosure. We will agree a disclosure timeline after triage and publish a GitHub security advisory when a fix is available.
